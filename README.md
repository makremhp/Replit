# Rewardly Telegram Mini App

واجهة Telegram Mini App عربية RTL لإدارة الرصيد، الأنشطة الاختيارية، طلبات السحب، وصفحة إثباتات السحب المجهولة.

## التشغيل

    npm install
    npm run dev

للبناء الإنتاجي:

    npm run build

## متطلبات Adsgram التي تراعيها الواجهة

- الأنشطة المدفوعة اختيارية وليست شرطًا لاستخدام المحفظة.
- لا توجد تعليمات للنقر على الإعلانات أو إيقاف الميزات الأساسية عند عدم المشاهدة.
- المكافآت معروضة بصياغة واقعية بدون ضمانات دخل.
- توجد صفحة مستقلة لإثباتات السحب مع إخفاء بيانات المستخدمين.

الواجهة الحالية Frontend أولي بحالة محلية لأغراض العرض والتكامل اللاحق مع Telegram Bot API وAdsgram.

هذا مشروع مستقل ويستخدم npm. تم استبدال صيغة `catalog:` الخاصة بـ pnpm بإصدارات
حقيقية في `package.json`، كما تم حذف lockfile المولّد داخل Replit حتى لا يشير
إلى مستودع داخلي غير متاح خارج Replit.

الواجهة تعرض 10 إعلانات Adsgram يومية بمكافآت بين `0.005` و`0.01 USDT`،
وتبدأ محفظة المستخدم من الصفر. زر **سجلات السحب** في أعلى الواجهة يفتح
صفحة تحتوي على آخر خمسة سجلات وهمية للعرض فقط.
